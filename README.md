# Portfolio Personal - Camila Eloiza Jazmin

Primera versión (v0.1) de mi portfolio web desarrollado para la materia **Aplicaciones Informáticas II** (6º E - Instituto San Agustín).

## Descripción
Sitio web estático diseñado para presentar mi perfil como estudiante de informática con orientación en robótica, programación y sistemas embebidos.

## Tecnologías utilizadas
- HTML5 semántico
- CSS3 (variables, Flexbox y CSS Grid)
- Git y GitHub Pages
