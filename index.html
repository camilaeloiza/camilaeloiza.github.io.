Bienvenido/a a mi portfolio

¡Hola! Soy Camila. Combino el desarrollo informático con la robótica educativa y aplicada para crear soluciones tecnológicas innovadoras.

Sobre mí

Soy estudiante de 6º año con orientación en Informática. Me fascina entender cómo el software interactúa con el mundo físico, lo que me llevó a especializarme en robótica, lógica de programación y electrónica básica.

Mi objetivo actual es continuar profundizando mis conocimientos en programación de microcontroladores, automatización y desarrollo web, aportando creatividad y análisis lógico a cada proyecto en el que participo.

Proyectos

Proyecto 1: Robot Móvil Automatizado (Arduino/ESP32)

Problema: Se requería un prototipo capaz de esquivar obstáculos y navegar en espacios reducidos de forma autónoma.

Solución: Diseñé e implementé un robot móvil controlado por microcontrolador con sensores de ultrasonido y motores DC.

Mi participación: Programación de la lógica de sensores en C++, ensamblado de circuitos y pruebas de navegación.

Tecnologías: Arduino (C/C++), Sensores HC-SR04, Electrónica Básica.

Evidencia: Código fuente en C++ y registro fotográfico del prototipo armado.

Aprendizaje: Comprendí el manejo de entradas/salidas digitales y analógicas, y el control de tiempos con microcontroladores.

Proyecto 2: Sistema de Monitoreo Ambiental

Problema: Necesidad de medir temperatura y humedad de un ambiente y mostrar las alertas en pantalla.

Solución: Creación de una estación meteorológica básica con sensor DHT11 y pantalla LCD que emite alertas según ciertos rangos.

Mi participación: Diagramación del circuito en Tinkercad, escritura del código y calibración del sensor.

Tecnologías: Tinkercad, C++, Pantalla LCD, Sensores DHT11.

Evidencia: Simulación interactiva y esquema eléctrico en Tinkercad.

Aprendizaje: Aprendí a prototipar y simular circuitos antes del ensamblado físico para prevenir fallas.

Proyecto 3: Sitio Web de Portfolio Personal

Problema: Crear una plataforma digital centralizada para publicar trayectoria, habilidades y proyectos tecnológicos.

Solución: Desarrollo de una página web estática, responsiva y semántica desplegada en la nube.

Mi participación: Maquetación en HTML5, diseño de estilos con CSS3 y publicación mediante GitHub Pages.

Tecnologías: HTML5, CSS3, Git, GitHub Pages.

Evidencia: Repositorio público en GitHub y sitio web activo en línea.

Aprendizaje: Dominio de etiquetas semánticas, modelo de caja y control de versiones colaborativo.
